# واحة — لعبة بناء مدينة صحراوية

لعبة استراتيجية مبسطة: تبني واحة تجارية وسط الصحراء، تدير الذهب والطعام والماء والسكان،
وتتابع تقدّم "القافلة الكبرى" كلما توسّعت واحتك.

## تشغيل اللعبة محليًا
افتح `index.html` مباشرة في أي متصفح (كروم يفضّل).

## رفعها على GitHub Pages (عشان تظهر بخاصية "التثبيت" من المتصفح)
1. أنشئ مستودع (repository) جديد على GitHub وارفع فيه كل الملفات:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - مجلد `icons/` بالكامل
2. من إعدادات المستودع Settings → Pages، اختار Branch: main، والمجلد root، واحفظ.
3. هتاخد رابط شبيه بـ:
   `https://username.github.io/repo-name/`
4. افتح الرابط ده من كروم على الموبايل، وادوس على الثلاث نقط → "التثبيت" أو
   "إضافة إلى الشاشة الرئيسية"، وهتتثبت اللعبة زي أي تطبيق عادي.

## ملاحظة
لازم الموقع يكون شغال على HTTPS (GitHub Pages بيوفر ده تلقائيًا) عشان خاصية
Service Worker والتثبيت تشتغل صح.
